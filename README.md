# Homebrew tap for Terminal Velocity (`tv`)

```sh
brew install onebit0fme/tap/tv
```

`tv` is a `git status` for build-flow health — is your build's speed real
throughput, or just thrashing? See
[onebit0fme/terminal-velocity](https://github.com/onebit0fme/terminal-velocity).

The formula here is updated automatically on each `tv` release.
